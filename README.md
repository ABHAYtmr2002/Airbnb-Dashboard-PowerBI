# Airbnb Dashboard (Power BI)

## 📊 Project Overview

This project analyzes **Airbnb listings, reviews, ratings, and host verification data** across multiple global cities using **Power BI**.
The objective is to understand **listing growth trends, customer review behavior, ratings performance, and host trust signals** to generate meaningful business insights.

The dashboard explores:

* Growth of Airbnb listings over time
* City-wise listing and review distribution
* Customer review behavior and travel patterns
* Ratings performance across cities
* Host verification and trust indicators

## 🔍 Key Insights

### 📌 Listings Growth Trends

* **2015** recorded the **highest number of new Airbnb listings**.
* In **2016 and 2017**, growth slowed due to **tighter local regulations** in several cities.
* Despite the slowdown, Airbnb became **profitable in the second half of 2016**.
* **2017 was the first full year of profitability**.
* From **2018 onward, growth stabilized**, and expansion slowed further in **2019 due to the COVID-19 pandemic**.
